# HapticBoost v1.3.1

本次发布保留已实测修复版的版本号：1.3.1 / versionCode 7。

## 修复

- 普通震动预览使用系统通知用途和默认振幅，修正与微信通知强度不一致的问题。
- 修复音频服务日志过长导致模式读取失败、微信来电增强中途停止的问题。
- 修复普通拨号来电中增强请求被原生铃声震动优先级压制的问题，改用有时长限制的来电用途播放器。
- 兼容实际设备的 Telecom 输出缩进，增强普通电话响铃识别。
- 补齐预览后的三路电压恢复、保存读回校验及恢复原厂时的进程停止顺序。

## 安装与升级

使用 `haptic-boost-v1.3.1.zip` 在 Magisk 中安装并重启，模块内含配套 App。
如果 App 自动安装失败，可手动安装 `HapticBoost-1.3.1-release.apk`。
本次修复同时涉及模块脚本与 APK 中的播放器，旧用户不能只更新 APK。
升级前请记录自定义参数，升级后打开 App 核对并保存设置。

## 验证

RMX3888 / Android 16 已实测普通通知预览、微信来电增强及普通拨号来电增强。
系统记录确认普通电话的增强脉冲实际播放，结束后停止并恢复日常档；用户确认效果正常。
App 协议 21 项、预览和恢复沙盒 9 项、电话和 VoIP 回归 6 组通过。
APK 签名、ZIP 内嵌 APK 和模块脚本一致性已校验。

仍未覆盖其他机型、重启后的全部通话场景。Root 播放器使用系统 Context 反射接口，
其他系统版本需要实机验证；脉冲间隔包含模式检查和进程启动开销。
完整记录见 [验证文档](../QA-1.3.1.md)。
