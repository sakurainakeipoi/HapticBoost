# HapticBoost v1.2.2

发布日期：2026-10-01

## 本次修复

- 修复静音模式下系统电话和微信语音来电仍触发补偿震动：仅在响铃或振动模式下启用来电增强。
- 来电过程中切到静音后，取消增强震动并恢复日常电压档位。
- 保留静音期间的接听状态跟踪，避免接听后恢复响铃模式时重新触发增强。
- 每次补偿震动前重新检查铃声模式；读取状态失败或超时时不启动增强。
- 更新 App 提示、PM8550B 理论通用条件和实测设备记录，并修正安装器的总开关提示。

## 验证

- 真我 GT5 Pro（RMX3888 / SM8650 / PM8550B / Android 16 / Kitsune Magisk 27001）：用户已完成电话与微信来电复测，确认本次修复有效。
- 四组离线行为回归通过，覆盖系统电话 / VoIP、静音 / 响铃 / 振动、切换模式、接听后的会话锁和读取失败场景。
- Release 构建与 lint 检查通过；APK 使用与 v1.2.1 相同的正式签名。
- ZIP 完整性、内嵌 APK、版本、LF 换行与脚本执行权限检查通过。

## 下载与兼容性

推荐安装 `haptic-boost-v1.2.2.zip`，其中已经包含配套 App。
单独安装 APK 只更新 App；本次静音修复位于模块脚本中，必须升级模块 ZIP 才能获得修复。

目前只有真我 GT5 Pro（RMX3888）完成整机实测。在相同驱动实现下，PM8550B 理论上通用，
但设备必须启用 `qcom-hv-haptics` 并实际提供 `vmax`、`fifo_vmax`、`cl_vmax` 三个可写节点。
其他机型与 PM8350B / PM5100 仍属于待验证候选，不能只凭“骁龙”或“X 轴线性马达”判断兼容。
详见[兼容性清单](https://github.com/sakurainakeipoi/HapticBoost/blob/main/docs/COMPATIBILITY.md)。

若仍安装着旧模块 ID `vibrate_boost`，请先卸载旧模块并重启，避免与
`haptic_boost_qcom` 同时运行。正常升级可在模块管理器中安装新的 ZIP 并重启。
