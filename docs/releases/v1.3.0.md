# HapticBoost v1.3.0

发布日期：2026-10-24

## 更新内容

- 新增“预览普通震动”和“预览触感反馈”两个独立按钮，按当前滑块数值预览 3 次，结束后恢复已保存的日常档。
- 保留未保存的调整：切换应用再返回时不覆盖正在调整的数值，显示“尚未保存”，支持“撤销修改”。
- 开放来电震动时长（100–3000 毫秒）和间隔（0–3000 毫秒），提供短促、均匀、长震三种节奏预设。
- 保存配置时先完整写入临时文件，再替换正式配置；应用后核对全部 13 个配置字段和三个日常电压节点，核对一致才提示成功。
- Root 命令增加 30 秒超时；模块缺失、节点不可写、配置写入失败或实际电压校验失败会显示相应提示。
- 修正 App 预览命令的振幅参数，预览失败时显示失败提示，并在预览流程结束时恢复日常档。

## 下载与升级

| 使用情况 | 下载与操作 |
|---|---|
| 已安装 v1.2.2 模块 | 下载 `HapticBoost-1.3.0-release.apk` 覆盖安装即可，保留现有模块配置，无需重刷模块或重启 |
| 首次安装，或模块早于 v1.2.2 | 下载 `haptic-boost-v1.3.0.zip`，在模块管理器中安装后重启；ZIP 已内嵌正式签名的新版 App |
| 检查下载完整性 | 对照附件 `SHA256SUMS.txt` 核对文件 SHA-256 |

本次功能升级位于 App，模块运行脚本与 v1.2.2 相同。APK 使用与 v1.2.2 相同的正式签名，
App 和模块版本号均为 1.3.0，versionCode 为 6。不要卸载旧 App 后再安装，直接覆盖升级即可。

重刷模块 ZIP 会带入默认 `config.sh`；已有自定义参数的用户请先记录或备份，升级后核对设置。
v1.2.2 以前的模块仍需升级 ZIP，才能获得静音模式不触发来电增强的修复。

## 验证与兼容性

- 14 项 App 逻辑回归通过，覆盖配置缺失、非法数值、读回不匹配、命令失败和超时。
- 4 组模块静音策略离线回归通过；模块脚本语法检查通过。
- Release 构建、Lint、APK 签名和包内版本检查通过；ZIP 完整性、内嵌 APK 一致性、脚本权限和 LF 换行检查通过。
- 本次 App 功能已在真我 GT5 Pro（RMX3888）测试：用户确认日常预览生效，切换应用后保留调整、撤销、节奏保存和实际电压读回均已验证。
- 本次未重新执行整套来电与重启回归；模块运行逻辑沿用 v1.2.2。

目前整机实测范围仍为 RMX3888。其他设备必须启用兼容的 `qcom-hv-haptics` 驱动，
并提供 `vmax`、`fifo_vmax`、`cl_vmax` 三个可写节点；不能只凭“骁龙”或马达型号判断兼容。
详见[兼容性清单](https://github.com/sakurainakeipoi/HapticBoost/blob/main/docs/COMPATIBILITY.md)。
